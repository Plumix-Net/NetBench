NetBench — инструмент нагрузочного тестирования HTTP для разработчиков, которым нужен быстрый и честный ответ на вопрос «как держит нагрузку мой API?» — без написания скриптов.

Создайте сценарий: адрес цели, число виртуальных пользователей, длительность, разгон, паузу между запросами и, если нужно, шаги запросов. Запустите прогон и следите за метриками в реальном времени:

• Запросы в секунду и живой график пропускной способности
• p95 задержки со своим графиком — обновляется четыре раза в секунду
• Доля ошибок, общее число запросов и открытые соединения

По завершении — полный отчёт: распределение задержки (min, p50, среднее, p95, p99, max), p95 во времени и коды ответов HTTP. Последние прогоны двух сценариев можно сравнить бок о бок, а отчёт — выгрузить в HTML, CSV или JSON.

Для тестирования своих сервисов:
• Высокая нагрузка с одного Mac: горячий путь движка без аллокаций, приложение скомпилировано в нативный код
• Можно http:// — удобно для локальных и стейджинговых стендов
• Сценарии и отчёты остаются на вашем Mac — без аккаунта, аналитики, рекламы и отслеживания

Запускайте NetBench только против своих серверов или тех, что вам разрешено тестировать.

NetBench — открытое приложение. Версия для Mac написана на .NET и Avalonia, версия для iPhone — витрина Plumix, Flutter-подобного UI-фреймворка для .NET.
